PROJETO0-INDIVIDUAL  
Projeto Desenvolvido na Unidade Curricular de LP1

Este projeto consiste na criação de um pequeno site em HTML5 e CSS3 com três páginas estáticas, cujo objetivo é apresentar um Curriculum Vitae digital.  
O principal foco do trabalho foi a estruturação das páginas, a utilização de CSS básico para formatação e a implementação de um layout simples e responsivo.

## Objetivo do Trabalho

- Exercitar a escrita de páginas HTML simples  
- Aplicar estilos CSS de forma básica  
- Seguir o layout pré-definido no enunciado  
- Organizar o código com clareza e boas práticas  
- Criar um pequeno CV totalmente funcional
